# 🎯 spoXpro Admin Panel - Полная Инструкция

## 🚀 Быстрый Запуск

### 1. Активируйте виртуальное окружение:
```bash
# Windows
backend\venv\Scripts\activate

# Linux/Mac
source backend/venv/bin/activate
```

### 2. Установите зависимости:
```bash
pip install jinja2 python-multipart aiofiles
```

### 3. Запустите сервер:
```bash
cd backend
uvicorn main:app --reload
```

### 4. Откройте админ панель:
```
http://localhost:8000/admin
```

## 🔧 API Endpoints

### Страницы
- `GET /admin/` - Dashboard
- `GET /admin/products` - Управление товарами
- `GET /admin/products/create` - Создание товара
- `GET /admin/products/{id}/edit` - Редактирование товара
- `POST /admin/products/create` - Сохранение нового товара
- `POST /admin/products/{id}/delete` - Удаление товара
- `GET /admin/orders` - Управление заказами
- `GET /admin/orders/{id}` - Детали заказа
- `POST /admin/orders/{id}/status` - Обновление статуса
- `GET /admin/statistics` - Статистика

### API
- `GET /admin/api/products/search` - Поиск товаров
- `GET /admin/api/orders/stats` - Статистика заказов
- `GET /admin/health` - Проверка здоровья

## 🚀 Развертывание

### Продакшен
```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите с несколькими воркерами
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

# Админ панель будет доступна по адресу:
http://your-domain.com:8000/admin
```

### Docker
```dockerfile
FROM python:3.10
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```
