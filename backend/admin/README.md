# spoXpro Admin Panel

Полнофункциональная админ панель для управления товарами, заказами и просмотра статистики spoXpro e-commerce платформы.

## 🚀 Возможности

### ✅ Управление товарами
- **Создание товаров** - Добавление новых товаров с полной информацией
- **Редактирование товаров** - Изменение всех параметров товара
- **Удаление товаров** - Безопасное удаление товаров
- **Просмотр товаров** - Список и сетка с фильтрацией
- **Поиск товаров** - Быстрый поиск по названию
- **Фильтрация по категориям** - Разделение товаров по категориям
- **Предварительный просмотр** - Live preview при создании/редактировании

### ✅ Управление заказами
- **Просмотр заказов** - Полный список заказов с деталями
- **Детали заказа** - Подробная информация о каждом заказе
- **Изменение статуса** - Обновление статуса заказов
- **Сортировка заказов** - По дате, сумме, статусу
- **Фильтрация по статусу** - Быстрая фильтрация заказов

### ✅ Статистика и аналитика
- **Dashboard** - Общая статистика системы
- **Графики и диаграммы** - Визуализация данных
- **Ключевые метрики** - Важные показатели бизнеса
- **Разбивка по категориям** - Анализ товаров по категориям
- **Анализ заказов** - Статистика по статусам заказов

## 🛠️ Установка

### 1. Установите дополнительные зависимости:
```bash
pip install jinja2 python-multipart aiofiles
```

### 2. Убедитесь что основное приложение запущено:
```bash
uvicorn main:app --reload
```

### 3. Откройте админ панель в браузере:
```
http://localhost:8000/admin
```

## 🔧 API Endpoints

### Основные страницы:
- `GET /admin/` - Dashboard
- `GET /admin/products` - Управление товарами
- `GET /admin/orders` - Управление заказами
- `GET /admin/statistics` - Статистика

### API для AJAX:
- `GET /admin/api/products/search` - Поиск товаров
- `GET /admin/api/orders/stats` - Статистика заказов

### Формы:
- `GET/POST /admin/products/create` - Создание товара
- `GET/POST /admin/products/{id}/edit` - Редактирование товара
- `POST /admin/products/{id}/delete` - Удаление товара
- `POST /admin/orders/{id}/status` - Обновление статуса заказа
